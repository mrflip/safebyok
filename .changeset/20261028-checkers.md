**`Validator` is renamed `Checkers`, and `Checker` and `objCheck` make one validator each.** A host's `Validator('bad_option', build, sources)` now reads `Checkers('bad_option', build, sources)`, and behaves as before. `Checker(build, kind?, sources?)` makes a single validator: `build` returns its schema, and the kind, after the builder, is 'bad_record' unless given (`const sidebarOpts = Checker(({ obj, bool, vaultlabel }) => obj({ vaultlabel, collapsed: bool.optional() }).strict(), 'bad_option')`). `objCheck(build, kind?, sources?)` is a `Checker` whose builder returns an object's fields, the object stripping what it does not take. Each refuses as a `Checkers` call's validators do. The exported validators are the same objects under the same names, and refuse as before. **Stored format:** unchanged.
