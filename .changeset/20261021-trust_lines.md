**Stored formats: `vault_key_epoch` is gone.** The vault props are format `safebyok-vault-v6`, each box `safebyok-box-v7` and each device mark `safebyok-mark-v5`, none holding a `vault_key_epoch`, and neither a way in nor a box binds one into its ctx. There is no migration before 1.0: a vault stored before this release reads as `damaged_vault` (never `newer_format`), which `delDamagedVault` clears so the user makes the vault again; a box stored before it lists as damaged; an older device mark reads as none. The snapshot's and the vault's `vault_key_epoch` are removed, `BoxSummary` and `SeenVault` lose the field, and a `BoxExpectation` is `{ vault_id, revision_tok }`: a VaultDB of your own compares only those in a box write, and the contract's line 3.8 is gone. Postgres hosts drop `safebyok_boxes` and `safebyok_vaults` and run `VaultTablesSql` again (no `vault_key_epoch` columns); Convex hosts clear the component's tables before deploying; a GraphQL server deploys its new schema (no `vault_key_epoch` on any type or input) with its clients. **The host's clock is checked once, at `Vault.make`**: one reading must be epoch milliseconds from 1981 to 2255, or make throws `bad_option`; every later reading is taken as it comes, rounded down to whole milliseconds. A later bad reading no longer drops the vaultKey or throws `bad_option`, and a clock that later throws fails the call that read it as `unexpected_error`. `vault.clock` is removed. **`Box`, `Wayin` and `Lease` no longer take the Vault object**: each takes one plain value of the vault props its encryption is bound to (scope and ids), and the time as a number. `Box.make(vaultProps, record)`, `Box.seal(vaultProps, now, boxlabel, whisper, vaultKey, opts)`, `Wayin.make(vaultProps, record, keyDeriver)`, `Wayin.seal(vaultProps, now, proof, deviceId, vaultKey)`, `Lease.make(scope, record)`, `Lease.grant(vaultProps, askPassphraseAt, vaultKeyPair)`, `lease.tryOpen(vaultProps, now)`; `lease.endsWithin(millis)` is now `lease.endsBy(instant)`. A whole `VaultProps` serves as each. The types `BoxVault`, `BoxHolder`, `WayinVault`, `WayinHolder`, `LeaseVault` and `LeaseHolder` are replaced by `BoxVaultProps`, `WayinVaultProps` and `LeaseVaultProps`; `box.vault`, `box.holder`, `wayin.vault`, `wayin.holder` and `lease.vault` give way to `box.vaultProps` and `wayin.vaultProps` (and a passphrase way in's `keyDeriver`). `Box.make` and `Box.seal` refuse vault props short of a field, and `Box.seal` a `now` that is no whole epoch millisecond, as `bad_option`. **A vault's boxlabel `validators` gate writes alone**: `getBox()`, `getWhisper()`, `useWhisper()` and `delBox()` hold a boxlabel to the floor only, so a name the host's check refuses with nothing under it is now `absent_box`, where it was `bad_label`; `putBox()` still refuses it as `bad_label`. `delBox()` reads no box before it deletes: a box another device deleted first is `absent_box`, as storage answers it, and a delete into a vault deleted elsewhere and not made anew is now `stale_write`, as its doc block said, where it was `absent_box`.
