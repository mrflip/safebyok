Empty: the new `safebyok` is private and the giver is not yet exported. What a caller of `ThingMinder` will see: `hello` caches the root box's listing, empty and bare, so `listingAt` answers `[]` for the root box from `hello` where it answered undefined until the first `list`, and a listener started before `hello` is told a `listing` event with `labelpaths: []`. Each box heard of from then on joins it, so a box got, written or noticed while the first `list` is in flight is no longer missing from the listing until the next `list`. The new `isListingBareAt(scoped)` is true of a listing cached but set by no `list` since `hello`; a box joining it, or an `invalidate`, leaves it bare, and any `list` ends it. The root box's listing now stays until `goodbye` whatever the host's `gcTime`, as its car does; any other listing is collected as before. A box joining a listing no longer counts as a fresh listing: the listing keeps the time its last `list` set it. `hello` still fetches nothing.
