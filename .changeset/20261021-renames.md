**Two stored fields are renamed: `vault_id` is `vault_tok` and `unlock_epoch` is `gate_epoch`.** The token a vault is given when it is made for its scope, which every box, wayin and lease is bound to, is now `vault_tok` (`vaultTok` in code), a token rather than an id because the scope finds the vault and the token only tells one life of that scope from the next. The counter that goes up whenever a wayin is added, changed or removed is now `gate_epoch` (`gateEpoch`). No behaviour changes and no format string changes, and there is no reader for the old names, as before 1.0.0 nothing binds backward. The names change wherever they appear: the vault props, a lease and a device mark's `seen` vault; a box's, a wayin's and a lease's visible fields and the snapshot's `passphrase` and `passkey` summaries; the `expected` of `putVaultProps`, `putBox`, `delBox` and `delVault` in every VaultDB; `Expectations.vaultIdMeets` is `Expectations.vaultTokMeets`; `Box.make`, `Wayin.make` and `Wayin.seal` take a `vaultTok`; and the contract in VAULTDB.md. **What a host sees with records written before:** vault props read as `damaged_vault`, and `delDamagedVault` cannot clear them, as it names the vault by the `vault_tok` the old record lacks; a lease reads as absent, so the vault reads locked; a device mark reads as none. The ctx a wayin, a box and a lease are sealed under binds their values and not these field names, so it does not change. Clear development data in storage and let the vault be made again. **Postgres** hosts drop `safebyok_boxes` and `safebyok_vaults` and run `VaultTablesSql` again (the columns are `vault_tok` and `gate_epoch`, and the constraints that name them follow). **Convex** hosts clear the component's tables before deploying (the validators and the `watchVault` query's answer say `vault_tok` and `gate_epoch`). **A GraphQL** server deploys its new schema with its clients (`vault_tok` and `gate_epoch` on `SafebyokVaultProps` and `SafebyokVaultPropsInput`, and `vault_tok` on the four expectation inputs, with `gate_epoch` on `SafebyokVaultPropsExpectationInput`). **IndexedDB** hosts clear the database (`indexedDB.deleteDatabase` for the `dbName` they gave `idbVaultDB`).
