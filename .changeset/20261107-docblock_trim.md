**`safebyok` exports `Patterns`, `MaxLabelChars` and `MaxUserIdChars`**, so an input can check a label or a `user_id` by the same pattern and length the vault does (`<input pattern={Patterns.label.source} maxLength={MaxLabelChars} />`); each `source` compiles under the `v` flag a browser gives an input's pattern. **A passphrase salt is 16 bytes, always:** a key deriver's `salt_bytes`, in a `keyDeriverSpec` and in the deriver a host hands `Bank.make`, must be 16 (`KeyDeriver['salt_bytes']` is the type `16`), and any other is refused as `bad_option`; a stored passphrase wayin whose `salt_b64` is not 22 base64url characters reads as damaged (`bad_record`). `checkSaltFits` leaves `safebyok/browser`, and `argon2idDeriver` and `safebyok-fastkey`'s derivers no longer check the salt they are handed. Whatever a key deriver throws from `deriveKeyBytes`, a `VaultError` too, reaches the host as `unexpected_error`, naming nothing it said. `safebyok-convex`'s README names the limit on a bank (past Convex's 16 MiB read, `tidyGone` throws and the watch goes quiet), and doc blocks in the storage packages are shortened. **`safebyok/testing` exports `_cheat_forgetShelf(dbname)`**, for tests only: the page forgets its shelf for that database, so the next store made over it opens a connection of its own. **`DeviceDB.listRawLeases()` answers each stored lease row beside the scopepath it is filed under**, `{ scopepath, row }` (`RawLease`), every row unchecked, not only those that are bags; **`delRawLease` takes that scopepath** (`LeaseScopepath`, the `[applabel, user_id, vaultlabel]` triple), checked only as three strings, so a host can delete a row filed under labels today's checks refuse, or one whose value has lost its scope. A `DeviceDB` subclass's `doListLeases` answers `RawLease`s and its `doDelRawLease` takes a `LeaseScopepath`. `safebyok` and `safebyok/storage` export both types, and `safebyok/storage` exports the `leaseScopepath` check; `safebyok` also exports the `LeaseDated`, `LeaseQuery` and `LeaseRow` types its `DeviceDB` names. Not publicly released, so nothing migrates. **Stored format:** a passphrase wayin's `salt_b64` is 22 characters only; one written at another length reads as damaged, and its vault opens by its other wayin, if it has one. **`KeyDeriver['salt_bytes']` is the literal 16**, so a host's deriver declared as a plain object needs `salt_bytes: 16 as const` or a `KeyDeriver` annotation; `PassphraseSaltBytes` is now exported from `safebyok` and `safebyok/browser`. **Types a signature names are now importable:** `safebyok` also exports `BankScope`, `Boxscope`, `Sidecar`, `FetchOpts`, `TimelyOpts`, `BoxPut`, `BoxPatch`, `BoxHalves`, `ClearsForGatingkind`, `VaultForGatingkind`, `Capacity`, `Awaitable`, `GoodOutcome`, `BadOutcome`, `RefusalFamilyForKind`, `RefusalMeta` and `VaultErrorOpts`; `safebyok/storage` also exports `Damagekind`, `Story`, `ConsistencyRefusal`, `RefusalFamily` and `RefusalFamilyForKind`. `safebyok/browser`, `safebyok/dom` and `safebyok/utils` add only `PassphraseSaltBytes` (browser).
