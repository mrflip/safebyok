`RefusalMeta` gains two optional fields, `stored_revision` and `staged_revision`, for a 'stale_write' this device makes itself when a stored record moves while an edit is being made: the revision storage now holds, and the one the edit had staged. No refusal a host meets today fills them yet; they come with the models that replace the vault and box classes.

**Stored format:** the stored box shape gains a `box_tok`, a random tok naming one life of a box (made when it is first stored, or remade over a tombstone), in those same models alone. No host uses them yet, so a host sees no change: the box records it puts and gets are as before.
