* **Decisions made**:
  - **The check lives in a tombstone public-props check, not the box record's check on the result.** It refuses at the bag the caller handed over, before any revision is made, and reads as the round-trip rule itself: the field is checked against its forced value, then ignored, since the revision writes `{}`. The record's check could not run in `tombstoneOf` without a sealed whisper (`BoxChecks.record` requires `whisper_sealed`); reaching it there would mean carrying the given sidecar into the revision so `recordOf` refuses later, after the lease has sealed, which is a worse place to refuse and a less plain read.
  - **The phrase is `TombstoneSidecarNotEmpty`** ("A box tombstone's sidecar is always `{}`."), the one the stored box's check already uses. The old `TombstoneSidecarGiven` told the caller to give no sidecar, which is no longer the rule; one phrase for one fact, whether met in a seal's props or a stored row.
* **Deviations** (each a contract change the Coach directed, stated as such):
  - `tombstoneOf(donor, { sidecar: {} })` refused before (`bad_record`, `TombstoneSidecarGiven`); it is now accepted, and so is `lease.seal(BaseBox, live, { am: 'x', sidecar: {} })`. A non-empty sidecar still refuses as `bad_record`; only its phrase changed, to `TombstoneSidecarNotEmpty`. No caller relied on the old throw: bank.ts's `tombstoneBox` passes `{ am: 'x', ... }` with no sidecar, safebyok-react's giver does not call `tombstoneOf`, and the one test that checked the old phrase is rewritten. Nothing stored changes.
* **Discoveries**:
  - `TombstonePublicProps` (shapes-sealers.ts, `Readonly<{ am: 'x', written_at?: EpochMillis }>`) has no `sidecar`, so the lease's tombstone overload and `Bank.tombstoneBox` still refuse `sidecar: {}` at the type level; the lease test reaches it through the general overload. The type is generic across Things (a gate has no sidecar), so I left it; widening it for boxes would belong with thread 6's per-kind bundles if wanted.
  - `tombstonePublicProps` still takes `am: 'a'` and ignores it, as `boxPublicProps` did here before. By the round-trip rule `am` would take only `'x'`; I left it, since the directive named the sidecar alone and the lease never hands `tombstoneOf` an `am: 'a'`.
