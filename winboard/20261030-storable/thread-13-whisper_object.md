* **Decisions taken**:
  * **The name** `WhisperHolder`: the object that holds a whisper as its `val`. Set aside: `WhisperBag` (`bag` already means something else here, STYLE *Naming*), `WhisperVal` (reads as the bare whisper), `WhisperObj` (says nothing), and anything confusable with the old `Whisper`.
  * **The refusal kinds.** A missing or null whisper or sidecar in `edit`/`send` refuses 'bad_option' under `namesBoth`, as thread 15 ruled, and is checked first. A whisper present but not `{ val }` (a bare string, `{}`, `{ val: null }`, an extra field) refuses 'bad_whisper' at the setter, `edit` and `send`, as the old whisper check does. In `build` it refuses 'bad_option', naming `whisper` or `whisper.val`, because `boxDna` refuses every field so: a nested validator refuses with the outer kind, and an exception just for the whisper would make `build` the one place a dna field refuses differently.
  * **The copy is frozen through**, `val` and all, by es-toolkit's `deepFreeze` (already a dependency; `src/box.ts` uses it): a host cannot change the box's whisper behind the setter's back, which would bypass `settle`. The parse copies first (the old check `structuredClone`s), so the host's own object is never frozen. Set aside: `.readonly()` alone, which freezes only the holder (the first commit did that; the second fixed it).
  * **The empty changeset**: nothing under `src/models/` is exported from `src/index.ts`, so no host sees `WhisperHolder`, `LOCKED` or `isLockedFUBag` yet.
  * **The setter checks its argument before `demandUnlocked`**, per the Coach's "arg checks first" (2026-10-31, thread 18's item 4 in the plan): a malformed whisper refuses 'bad_whisper' even while locked.
* **Deviations**:
  * **`isLockedFUBag` checks identity, not the brand.** A spread copies own enumerable symbol keys, so `{ ...LOCKED }` carries the brand, and a brand check would answer true for it, against the directive's own test list ("false for a spread copy"). A non-enumerable brand would defeat the spread but not `Object.defineProperties` or `structuredClone`-style copying, and would still not be identity. The brand stays: it gives `LockedBag` a nominal type and shows in devtools. Set aside: `Symbol.for` (anyone can mint it: the point of the directive), a class instance (more machinery for one frozen object).
* **Discoveries**:
  * `{ val: 'LOCKED' }` is an ordinary whisper and is exposed; a spread copy of LOCKED is refused 'bad_whisper' at the setter, since it is neither the bag nor `{ val }`. Both are tested.
  * The old `whisper` check admits a bag or an array as well as a string, so a freeze of the holder alone left `box.whisper.val.apiKey = ...` open. Hence the deep freeze, tested at the checker and at the setter.
* **For the Coach**:
  * The LOCKED directive was taken whole, with the identity check above as the one departure.
