# Coming back from a compaction

You were compacted. The threads kept running; what you lost is your place. The summary is a
sketch, and can be wrong with confidence: the plan, git, `gh` and the sprint doc are the record.

1. Read the plan's header and, before your next handoff, the progress document.
2. Find where each thread stands: *Progress*, `gh pr list`, `git worktree list`, the tail of
   `ohai.log`. `ListAgents` names the agents you can still resume; a blocked worker it does not
   name goes to a fresh worker, with the rework handoff. What all these leave unexplained is §4's
   state that nothing explains.
3. Your turbochat bookmark went with the summary: read *Open Matters* whole, once, to set a new
   one, and reload the Docs guides before your next write to the doc.
4. Finish §3 for any report you hold, then decide (§4).

A ruling settles the question it answered, as firmly as it was given: read it beside that
question, where it was carried back. Words of the Coach's that seem to bar something else are, on
their own, no reason to revert work or to stop and ask.
